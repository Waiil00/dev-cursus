HTML Tags & Attributes Reference

A practical static HTML cheat sheet with descriptions and examples.

Structure Text Links Media Lists Semantic Tables Forms Interactive Global Attributes ARIA Events

1. Document Structure

TagDescriptionExample
<html>Root element of an HTML document.<html lang="en">
<head>Contains metadata and resources.<head>...</head>
<body>Contains visible page content.<body>Hello</body>
<title>Sets the browser tab title.<title>My Site</title>
<meta>Defines metadata.<meta charset="UTF-8">
<link>Connects external resources such as CSS.<link rel="stylesheet" href="style.css">
<style>Contains internal CSS.<style>body{...}</style>
<script>Loads or contains JavaScript.<script src="app.js"></script>
<base>Defines the base URL for relative URLs.<base href="/">
<noscript>Content displayed when JavaScript is unavailable.<noscript>Enable JS</noscript>

</a>

4. Images, Audio & Video

TagDescriptionImportant attributes

<video>Embeds video.src, controls, poster, autoplay, loop, muted
<track>Provides subtitles/captions for media.kind, src, srclang, label, default
<iframe>Embeds another webpage.src, width, height, sandbox, loading

8. Forms & Inputs

<form action="/submit" method="post">
  <label for="email">Email</label>
  <input
    id="email"
    name="email"
    type="email"
    placeholder="you@example.com"
    required>

  <label for="country">Country</label>
  <select id="country" name="country">
    <option value="ma">Morocco</option>
    <option value="fr">France</option>
  </select>

  <textarea name="message" rows="5"></textarea>

  <button type="submit">Send</button>
</form>
ElementDescriptionImportant attributes
<form>Form container.action, method, enctype, target, autocomplete, novalidate
<label>Label for a form control.for
<input>Single-line/input control.type, name, value, placeholder, required, disabled, readonly, checked, min, max, step, pattern, minlength, maxlength, accept, multiple
<textarea>Multiline text input.rows, cols, placeholder, maxlength, required, readonly
<button>Clickable button.type, name, value, disabled, autofocus
<select>Dropdown/list control.name, multiple, size, required, disabled
<option>Option in a select/datalist.value, selected, disabled, label
<optgroup>Groups options.label, disabled
<fieldset>Groups form controls.disabled, form, name
<legend>Caption for a fieldset.Global attributes.
<datalist>Suggested input values.id
<output>Displays a calculation/result.for, form, name
<progress>Progress indicator.value, max
<meter>Scalar measurement within a known range.value, min, max, low, high, optimum

11. Accessibility / ARIA

ARIA adds accessibility semantics. Prefer native HTML elements when they already provide the required semantics.

AttributePurpose
aria-labelAccessible name supplied directly.
aria-labelledbyUses another element as the accessible name.
aria-describedbyAssociates descriptive text.
aria-hiddenControls whether an element is exposed to assistive technology.
aria-expandedIndicates expanded/collapsed state.
aria-controlsIdentifies controlled content.
aria-currentIdentifies the current item in a set.
aria-liveDefines live-region announcement behavior.
aria-disabledCommunicates disabled state.
aria-selectedCommunicates selection state.

15. Complete Mini Example

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>My Website</title>
  <link rel="stylesheet" href="style.css">
</head>

<body>

  <header>
    <h1>My Website</h1>

    <nav>
      <a href="#home">Home</a>
      <a href="#about">About</a>
    </nav>
  </header>

  <main>

    <section id="home">
      <h2>Welcome</h2>
      <p>This is my <strong>HTML</strong> page.</p>
      <img src="photo.jpg"
           alt="My photo"
           width="300">
    </section>

    <section id="about">
      <h2>About Me</h2>

      <ul>
        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>
      </ul>

      <form action="/submit" method="post">
        <label for="email">Email</label>
        <input
          id="email"
          name="email"
          type="email"
          required>

        <button type="submit">
          Send
        </button>
      </form>
    </section>

  </main>

  <footer>
    <p>&copy; 2026 My Website</p>
  </footer>

</body>
</html>
